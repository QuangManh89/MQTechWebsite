# Frontend Design Skill

## Workflow
1. Identify primary audience, task, device context, brand attributes and conversion goal.
2. Define a visual concept before building components.
3. Establish hierarchy, grid, typography, spacing, color and interaction states.
4. Design responsive layouts for small mobile, tablet and desktop.
5. Include loading, empty, error, success, disabled and validation states.
6. Check contrast, keyboard navigation, focus visibility, labels and reduced-motion preferences.
7. Validate the rendered result rather than judging only source code.

## MQTech direction
Communicate technical competence, trust, clarity and local accessibility. Make the primary action to request service obvious. Use real, verified contact and location information only. Avoid generic template-like hero sections, excessive gradients, decorative clutter, fake reviews, and unsupported claims.

## Deliverables
- Page hierarchy and layout rationale.
- Component inventory.
- Responsive behavior.
- Interaction/state notes.
- Accessibility checklist.

## Acceptance criteria
A first-time visitor can identify the services offered, how service is delivered, how to submit a request, and that appointments require manual confirmation.
