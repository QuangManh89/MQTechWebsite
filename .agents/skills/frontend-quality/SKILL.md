# Frontend Quality Skill

## Checklist
- Semantic HTML and correct heading hierarchy.
- Labels and accessible names for all controls.
- Keyboard navigation and visible focus.
- Contrast and status cues not based on color alone.
- Responsive layout at narrow and wide viewports.
- Loading, empty, error, success and disabled states.
- Form validation is understandable and preserves safe user input.
- Images have appropriate alt text; decorative images are ignored by assistive technology.
- No unnecessary client-side JavaScript or large dependencies.
- No console errors or hydration warnings in tested flows.
- Motion respects reduced-motion preferences.
- Layout and typography remain usable with zoom and longer Vietnamese text.

## MQTech priorities
- Request form must work comfortably on mobile.
- Service options and on-site/store choices must be clear.
- Make manual appointment confirmation explicit.
- Admin tables and filters must remain usable on common laptop screens and degrade sensibly on mobile.

## Evidence
Record viewport/device, browser, tested pages, defects, and whether each check was manual or automated.
