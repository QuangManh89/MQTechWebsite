# Quality Strategy

## Automated checks
Adapt commands to the actual package manager and package scripts:
- Lint.
- Type check.
- Unit and integration tests.
- Playwright E2E tests.
- Production build.
- Dependency and secret scanning.
- Database migration checks.
- Accessibility and SEO checks where automation is appropriate.

## Manual checks
- Visual review on mobile and desktop.
- Keyboard-only navigation.
- Form validation and error clarity.
- Admin workflow usability.
- Local business information accuracy.
- Deployment health and recovery readiness.

## Evidence format
For every check, capture command/tool, environment, result, scope, and any exclusions. Do not mark unrun checks as passed.
